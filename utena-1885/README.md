# Utena, 1885

An alternate history in eighteen parts: what if all thirty-nine episodes of
*Revolutionary Girl Utena* (1997) had first appeared as a pseudonymous illustrated
newspaper serial in Tokyo in 1885?

- `src/` — the page, in numbered fragments (head and styles, masthead, then one file per Part).
- `build.sh` — concatenates the fragments into `dist/utena-1885.html` and reports any
  unresolved `(to confirm)` markers.
- `dist/utena-1885.html` — the built page (published as an Artifact).
- `research/` — the real-history research notes the page was checked against, each
  fact with the page it was read from.

Labels in the text: **documented** (real history, sourced), **inference** (what
follows from it), **choice** (where one outcome was picked among several).
